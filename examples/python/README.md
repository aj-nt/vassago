# Python Examples

These examples use the Mnemosyne Python SDK (`mnemosyne-sdk`).

## Installation

```bash
pip install mnemosyne-sdk
```

## Examples

| File | Description |
|------|-------------|
| `demo.py` | Add memory, read hot block, search, subscribe to Telepathy events |
| `quickstart.ipynb` | Jupyter notebook walkthrough of the full SDK API |

## Running

Start the daemon first:

```bash
mnemosyne start
```

Then run the demo:

```bash
python demo.py
```

Or open the Jupyter notebook:

```bash
jupyter notebook quickstart.ipynb
```
